# 실사용자 모집 글 (T18)

> 베타 테스터 모집용. 에브리타임·학과/국비 단톡·지인에게. 결제는 테스트라는 점과 피드백 창구를 꼭 넣는다.

## 짧은 버전 (단톡방)

```
[베타 테스터 구해요] 동네 이웃과 대용량 상품 반띵하는 "반띵"을 만들고 있어요 🙏
휴지 30롤, 생수 24병처럼 혼자 사긴 많은 걸 동네 사람과 나눠 사는 서비스예요.

👉 https://d3i3a9qd0hlqm6.cloudfront.net

- 결제는 토스 "테스트 결제"라 실제 돈이 나가지 않아요 (실제 거래도 안 돼요)
- 혼자 들어와도 예시 공구에서 "이 공구로 체험하기"로 처음부터 끝까지 해 볼 수 있어요 (1~2분)
- 써 보고 불편한 점은 화면 아래 "문의·피드백"에 남겨 주세요. 고치면 "업데이트 노트"에 올려요
```

## 긴 버전 (에브리타임·커뮤니티)

```
제목: 자취생 공동구매 서비스 베타 테스터 구합니다 (5분, 실제 결제 없음)

국비 과정에서 개발 공부하며 만든 "반띵"이라는 서비스예요.
동네 이웃과 온라인 대용량 상품을 나눠 사는 공동구매인데,
참여하면 바로 결제되고, 인원이 다 차면 자동 확정, 못 채우면 전원 자동 환불되는 구조예요.

해 주시면 좋은 것
1. 가입 → 동네 설정
2. 예시 공구에서 "이 공구로 체험하기" (봇 이웃과 참여 → 확정 → 수령까지 1~2분)
3. 쇼핑 앱에서 상품 "공유 → 복사" 후 공구 열기에 붙여 넣어 보기
4. 이상하거나 불편한 점을 "문의·피드백"에 한 줄이라도

안내
- 결제는 토스 테스트 결제라 실제 돈이 나가지 않아요
- 실제 상품 거래는 이뤄지지 않아요 (베타)
- 모으는 정보: 이메일·닉네임·동네(약 100m 단위). 자세한 건 개인정보처리방침 참고
- 탈퇴·삭제 원하시면 문의로 남겨 주세요

👉 https://d3i3a9qd0hlqm6.cloudfront.net
```
