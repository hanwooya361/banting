# 반띵 PRD

> 원본 기획서: Claude 문서 "자취생 공동구매 서비스 기획서" (2026-11-11). 이 파일이 저장소 기준 최신본.

## 1. 개요
| 항목 | 내용 |
| --- | --- |
| 서비스 | 반띵: 동네 이웃과 온라인 대용량 상품을 나눠 사는 공동구매 |
| 형태 | 1인 개인 프로젝트, 2~3주 |
| 대상 | 일반 사용자 (1~2인 가구, 자취생 중심) |
| 운영 방식 | 티켓 단위로 매일 CI/CD 배포, 실사용자 문의·피드백을 반영해 재배포 |

## 2. 문제
- 1~2인 가구는 대용량을 혼자 사기 부담스럽고, 당근 소분모임은 2025년 상반기 전년 대비 411% 증가
- 지금은 당근·오픈카톡 글로 모아 한 명이 대표로 사고 계좌이체로 n분의 1을 받는다
- 불편
  - 정산: 잔돈·늦은 입금으로 다툼, 총대가 돈을 받으러 다님
  - 노쇼·이탈: 돈을 먼저 안 내니 마감 직전에 빠져도 막을 수단이 없음
  - 수령 조율: 채팅으로 시간·장소를 맞추기 번거로움
  - 진행 상황: 무엇이 언제 어떻게 진행되는지 보기 어려움

## 3. 차별점
1. 참여 = 결제: 참여할 때 내 몫을 먼저 결제
2. 자동 확정·자동 환불: 마감까지 인원이 차면 확정, 못 채우면 전원 자동 환불
3. 수령 시간 투표: 개설자가 올린 후보에 참여자가 투표

유사 서비스: 카카오 오늘 공구(판매자 주도, 종료 시 자동 결제), N빵(사용자 제안, 결제는 앱 밖), 공동구매 나비(지역 소상공인 공구), 당근 소분모임(결제·정산 기능 없음)

## 4. 사용자
| 역할 | 하는 일 |
| --- | --- |
| 개설자 | 공구 개설(본인 몫 결제), 수령 후보 등록, 상품 구매, 나눔 |
| 참여자 | 탐색, 참여·결제, 수령 투표, 수령 확인, 후기 |
| 관리자 | 문의·신고 처리, 업데이트 노트 작성, 통계 |

대표 시나리오: 휴지 30롱(30,000원)을 3명이 10롱씩 나눠 사기
1. 개설자가 "균등 3명 · 1인 10,000원 · 마감 3일 뒤"로 개설하고 본인 몫 결제, 수령 후보 2~3개 등록
2. 이웃 2명이 반경 안 목록에서 보고 참여·결제, 수령 후보에 투표
3. 인원이 다 차면 확정, 투표 1위 일정이 수령 일정이 되고 알림
4. 개설자가 상품을 사서 약속 장소에서 나눔, 참여자가 "수령 완료"
5. 전원 수령 확인(또는 기한 경과) 시 수수료를 뗀 금액이 개설자에게 정산 기록
마감까지 인원 미달이면 전원 자동 환불, 공구는 실패

## 5. 결정 사항
| 항목 | 결정 |
| --- | --- |
| 상품 범위 | 온라인 구매품만, 상품 링크 필수 |
| 금액 방식 | 균등 n분의 1 또는 수량별, 개설자가 선택 |
| 개설자 결제 | 개설자도 참여자로 포함, 개설 시 본인 몫 결제 |
| 책임 범위 | 미수령·미구매는 당사자 간 문제, 플랫폼은 신고·이력 표시로 대응 |
| 수익 모델 | 거래당 수수료 |
| 동네 범위 | 위치 기반 반경 검색 |
| 결제 | 토스페이먼츠 테스트 모드, 정산은 기록만 |
| 배포 | 프론트 S3 + CloudFront, 백엔드 EC2, DB RDS. Python AI 모델·서버는 쓰지 않음 |

## 6. 남은 결정
- [ ] 정산 시점 (기본안: 전원 수령 확인 또는 확정 후 3일 경과 시 자동)
- [ ] 수수료 비율과 부담 주체 (기본안: 개설자 정산액에서 3%, 설정값으로 둠)
- [ ] 실사용자 모집 채널
- [ ] 도메인 구매

## 7. 기능 범위
| 영역 | MVP | 추가 (피드백 따라) |
| --- | --- | --- |
| 회원 | 가입·로그인(JWT), 위치 기반 동네 설정, 내 정보 수정·탈퇴 | 카카오 로그인, 현재 위치 동네 인증 |
| 공구 | 개설(링크 필수, 사진, 금액 방식), 수정·삭제(참여자 없을 때), 목록·상세·반경·카테고리·검색 | 찜, 최근 본, 인기, 수요 조사글 |
| 참여·결제 | 참여 = 결제, 마감 전 취소·환불, 마지막 자리 동시성 | 대기자 자동 승격 |
| 자동화 | 마감 스케줄러(확정/실패·환불), 결제 대기 만료 처리 | 마감 임박 알림 |
| 수령 | 후보 등록·투표, 수령 확인 | 영수증 업로드, 미수령 신고 |
| 정산 | 수수료 차감 정산 기록 | 정산 내역 화면 |
| 신뢰 | 중개자 고지 | 후기·매너 온도, 노쇼 이력 |
| 운영 | 문의·피드백 게시판, 업데이트 노트 | 관리자 페이지(회원·공구·신고·통계) |
