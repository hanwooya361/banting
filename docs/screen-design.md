# 반띵 화면 설계

> 모바일 우선 반응형. PC에서는 가운데 정렬된 넓은 카드 레이아웃.

## 1. 화면 목록
| ID | 화면 | 경로 | 로그인 | 주요 요소 |
| --- | --- | --- | --- | --- |
| S01 | 홈 (내 동네 공구) | `/` | 선택 | 동네 이름·반경 칩, 카테고리 탭, 정렬(마감임박/최신), 공구 카드 목록 |
| S02 | 공구 상세 | `/group-buys/:id` | 선택 | 사진, 상품 링크, 진행 바(채워진 수량/전체), 1인 금액, 마감 카운트다운, 수령 후보·투표, 참여 버튼 |
| S03 | 공구 개설 | `/group-buys/new` | 필수 | 링크, 상품명, 사진, 카테고리, 총가·총수량·단위, 금액 방식(균등/수량별), 인원 또는 최소 수량, 마감일, 수령 후보 1~3개 |
| S04 | 참여 수량 선택 | 상세 하단 시트 | 필수 | 수량(수량별일 때), 내 결제 금액, 중개자 고지 체크 |
| S05 | 결제 | `/payments/checkout` | 필수 | 토스 결제위젯 |
| S06 | 결제 결과 | `/payments/success`, `/payments/fail` | 필수 | 승인 처리 중 → 완료/실패 안내 |
| S07 | 내 공구 | `/me/group-buys` | 필수 | 탭: 참여 중 / 개설한 / 지난 공구, 상태 배지, 수령 확인 버튼 |
| S08 | 동네 설정 | `/me/location` | 필수 | 현재 위치 버튼 또는 지도에서 선택, 반경(500m/1km/3km) |
| S09 | 로그인·가입 | `/login`, `/signup` | - | 이메일, 비밀번호, 닉네임 |
| S10 | 내 정보 | `/me` | 필수 | 닉네임 수정, 정산 내역(추가), 탈퇴 |
| S11 | 문의·피드백 | `/inquiries` | 필수 | 유형(버그/기능 제안/기타), 내용, 내 문의와 답변 |
| S12 | 업데이트 노트 | `/notices` | 선택 | "받은 피드백 → 반영 내용" 목록 |
| S13 | 관리자 | `/admin` | 관리자 | 문의 답변, 노트 작성 (MVP는 문의·노트만) |

## 2. 주요 흐름
1. 처음 방문 → 홈(서울시청 기준 기본 목록) → 참여하려면 로그인 → 동네 설정 → 홈
2. 개설: S03 작성 → 본인 몫 결제(S05) → 성공 시 공구 공개, 상세로 이동
3. 참여: S02 → S04 수량 선택 → S05 결제 → S06 성공 → S02(내 참여 표시, 투표 가능)
4. 확정 후: S07에서 수령 일정 확인 → 수령 후 "받았어요" 버튼

## 3. 상태 배지와 카피
| 상태 | 배지 | 상세 안내 문구 |
| --- | --- | --- |
| 개설 대기 | 결제 대기 | 내 몫을 결제하면 공구가 공개돼요 |
| 모집 중 | 모집 중 | N명 더 모이면 반띵 확정! / N개 남았어요 |
| 확정 | 확정 | 다 모였어요. 수령 일정: 11/15(토) 오후 2시, OO편의점 앞 |
| 수령 대기 | 나눔 준비 | 개설자가 상품을 샀어요. 약속 장소에서 만나요 |
| 완료 | 완료 | 반띵 완료! 후기를 남겨주세요 |
| 실패 | 무산 | 인원이 모이지 않아 전액 환불했어요 |

## 4. 공통 요소
- 푸터: "반띵은 통신판매중개자로서 거래 당사자가 아니며, 상품 구매·전달에 대한 책임은 개설자와 참여자에게 있습니다." + 문의 링크 + 업데이트 노트 링크
- 결제 직전(S04)에 같은 내용 체크박스
- 금액 표시는 항상 원 단위, 천 단위 콤마
- 위치는 동네 이름만 표시, 좌표 노출 금지
